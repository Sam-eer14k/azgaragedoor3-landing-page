# AZ Garage Door

Landing page for AZ Garage Door, an owner-operated garage door repair service
working Phoenix, Scottsdale, Tempe, Mesa and Chandler since 2011.

## What's here

```
index.html          The site. Generated by build.ps1. Open it or serve it.
assets/             Logo, favicons, hero photo, and the service illustrations.
src/                Sources the site is built from. Edit these, not index.html.
wordpress-theme/    The same site as an installable WordPress theme (PHP).
docs/WIREFRAME.md   The conversion wireframe the layout was built from.
build.ps1           Rebuilds index.html and syncs the theme.
.nojekyll           Tells GitHub Pages to serve assets/ verbatim.
```

## View it locally

Open `index.html` in a browser. For the Google Fonts to load reliably, serve it
over HTTP rather than the `file://` protocol:

```bash
# Python 3
python -m http.server 8000
# then visit http://localhost:8000
```

## Host it on GitHub Pages

1. Push this folder to a GitHub repository (see below).
2. In the repo, go to **Settings > Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick
   the `main` branch and the `/ (root)` folder, and save.
4. The site goes live at `https://<your-username>.github.io/<repo-name>/` within
   a minute or two.

The repository is already initialised with one commit on `main`, so you only
need to add the remote and push:

```bash
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```

`index.html` is at the repo root, so Pages serves it as the home page with no
extra configuration. Every path in the page is relative, so it works whether the
repo is served from a user site or a project subfolder.

## Editing the site

`index.html` is generated with all CSS and JS inlined, so do not edit it by hand.
Edit the sources instead:

```
src/_body.html      Page markup
src/css/theme.css   All styles
src/js/main.js      All interaction
```

Then rebuild:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

That regenerates `index.html` and copies the CSS, JS and images into the
WordPress theme, so both deliverables stay in step. `wordpress-theme/front-page.php`
is also generated and will be overwritten; the other PHP templates are edited in
place.

## The WordPress theme

`wordpress-theme/` is a self-contained theme (`style.css`, `front-page.php`,
`functions.php`, `header.php`, `footer.php`, `index.php`, `assets/`). GitHub
Pages ignores it because Pages does not run PHP. To use it, copy the folder into
a WordPress install under `wp-content/themes/`, activate it, then set a static
front page under **Settings > Reading**. The phone number and email are editable
under **Appearance > Customize > AZ Garage Door contact**.

## Notes

- The hero photo is served at two sizes: `hero.jpg` (1600px, 205 KB) for desktop
  and `hero-900.jpg` (84 KB) below 700px, swapped with a `<picture>` element.
- Headings use Barlow Condensed and body copy uses Archivo, both from Google
  Fonts, so the live site needs an internet connection for the intended
  typography.
- The six service images are generated illustrations, not photographs. Swap in
  real job photos at 900x620 under the same filenames in
  `assets/images/placeholders/` and rerun `build.ps1`.
- Motion respects `prefers-reduced-motion`: the custom cursor, count-up, scroll
  reveals, Ken Burns zoom, carousel autoplay and the pulsing status dot are all
  disabled, and counters jump straight to their final values.
- Verified with no horizontal overflow at 375, 768, 1024, 1280 and 1440px, no
  heading-level skips, no tap targets under 44px, and no missing alt text.
